Access the project materials webpage at [https://mohsin-bd.github.io/pedl-bricks-to-blocks-materials/](https://mohsin-bd.github.io/pedl-bricks-to-blocks-materials/).

This repository contains open materials for the PEDL: Bricks to Blocks project.

- `index.html` serves the public downloads page.
- `resources/2025-10-26 Block_Producers_List_MMH.pdf` is the block producer list distributed through the site.
- `resources/Workshop_Training_Manual.pdf` is the workshop training manual PDF distributed through the site.
- `resources/PEDL B2B Workshop Booklet.pdf` is the workshop booklet PDF distributed through the site.
- `resources/Workshop_Training_Manual.pptx` is the retained source deck for the training manual presentation.
